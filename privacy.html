Hob Analytics privacy policy

Last updated 21 November 2026

Hob Analytics is a private reporting tool used only by the owner of the Hob the Peasant YouTube channel. It isn't offered to anyone else.

What it reads

Hob Analytics uses YouTube API Services. With the channel owner's permission, given through Google sign-in, it has two read-only permissions:

  • View your YouTube account: the channel's name and ID, and its videos' titles, publish dates, privacy and upload status, and public view, like and comment counts.
  • View YouTube Analytics reports for your YouTube content: views, watch time, audience retention, subscribers, likes, comments, shares, traffic sources, impressions and click-through rate for the owner's own channel.

It reads only the data above. It can't upload, change or delete anything, and it doesn't read the text of comments, messages, email or any other Google data.

How the data is used

Only to build the owner's daily channel report and dashboard.

Where it's kept

  • The Google sign-in token is stored on the owner's own computer, readable only by the owner's user account. The report history is kept on the same computer.
  • Each day's report is also uploaded to a private dashboard on claude.ai (Anthropic) that only the owner can open.

Sharing

Hob Analytics doesn't sell the data, doesn't share it with anyone else and doesn't use it for advertising. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies

This website sets no cookies and runs no trackers or ads. The tool itself runs only on the owner's computer.

YouTube and Google terms

By using Hob Analytics you agree to be bound by the YouTube Terms of Service. How Google handles your data is described in the Google Privacy Policy.

Removing access

You can remove Hob Analytics' access at any time on your Google Account's third-party access page. After that it can't read anything new. The stored history and the dashboard can be deleted at any time.

Contact

Questions about this policy: open an issue on this site's GitHub repository.
